# BuildPath — Turn Ideas Into Learning Roadmaps

Describe what you want to build and get a structured learning roadmap with required skills, technologies, and step-by-step learning order.

## Features

- **Project Analysis**: Get a clear breakdown of any project idea.
- **Learning Roadmap**: Step-by-step guide to mastering the necessary skills.
- **Tech Stack Options**: Multiple ways to build your idea.
- **Architecture Overview**: Understand the layers of your application.
- **Progress Tracking**: Check off steps as you complete them.
- **Export Options**: Download your roadmap as Markdown or PDF.

## Getting Started

### Prerequisites

- Node.js & npm (or bun)

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/gurbaazsingh411-hub/devxroadmap
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies Used

- **Vite**
- **TypeScript**
- **React**
- **shadcn-ui**
- **Tailwind CSS**
- **Supabase** (Backend & Edge Functions)
- **Framer Motion** (Animations)

## Deployment

This project can be deployed to any platform that supports static site hosting (like Vercel, Netlify, or GitHub Pages). The Supabase Edge Functions should be deployed to your Supabase project.
